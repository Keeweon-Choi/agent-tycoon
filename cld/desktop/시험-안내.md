# Agent Tycoon 데스크톱 앱 시험 안내 (Windows, 이 PC)

이 PC에서 Windows 앱을 깔고, WSL(Ubuntu-22.04)에서 이미 돌고 있는 사무실에 붙는지 봅니다.
앱은 이 경로로는 데몬을 새로 깔거나 바꾸지 않습니다. 돌고 있는 데몬을 찾아서 그대로 씁니다.

## 1. 설치

1. 탐색기 주소창에 아래를 붙여 넣고 엔터를 누르면 설치 파일이 보입니다.

   ```
   \\wsl.localhost\Ubuntu-22.04\home\choi\projects\cld-gui\.worktrees\out\desktop
   ```

2. `Agent Tycoon_0.1.0_x64-setup.exe`를 더블클릭합니다. 관리자 권한은 필요 없습니다(내 계정에만 설치).
   - 파란 SmartScreen 창이 뜨면 **추가 정보 → 실행**. 서명 안 한 시험판이라 그렇습니다.
   - 설치 파일이 약 100 MB입니다. 사무실 프로그램 묶음 둘(Windows용, WSL용)이 들어 있어서 그렇습니다. 이번 시험에서는 쓰지 않습니다.
3. 설치 위치는 `%LOCALAPPDATA%\Agent Tycoon`입니다. 예전 **Pixel Office**는 지워지지 않고 옆에 그대로 남습니다.

## 2. 처음 실행

시작 메뉴에서 **Agent Tycoon**을 엽니다.

> 전에 Pixel Office를 쓰셨다면 두 앱이 설정 파일을 같이 씁니다. 그래서 첫 화면 대신 예전 연결(주소나 SSH)로 바로 갈 수 있습니다.
> 첫 화면부터 보려면 앱을 끄고 `%APPDATA%\dev.cldgui.pixeloffice\config.json`의 이름을 `config.json.bak`으로 바꾼 뒤 다시 엽니다. 시험이 끝나면 앱이 새로 만든 `config.json`을 지우고 `.bak`의 이름을 되돌리면 Pixel Office 연결이 그대로 돌아옵니다.
> 이름을 바꾸기 싫으면 **Ctrl+,** (또는 트레이 아이콘 → 설정) → 연결 방법 **이 컴퓨터** → **다음**으로 고르는 화면을 바로 열 수 있습니다(아래 "다른 방식으로 실행"과 같은 화면).
> Agent Tycoon에서 **이 컴퓨터**를 저장하면 Pixel Office는 그 설정을 몰라 설정 화면부터 엽니다. 위처럼 `.bak`을 되돌리면 풀립니다.
> Pixel Office와 Agent Tycoon은 한 번에 하나만 뜹니다. 둘째로 연 쪽은 먼저 뜬 창을 앞으로 가져옵니다. 시험 중에는 Pixel Office를 트레이에서 **종료**해 두세요.

화면마다 볼 것:

1. **어디서 사무실을 열까요?**
   - 두 버튼이 보이면 정상입니다: **이 컴퓨터에서 시작**, **다른 컴퓨터에 연결**.
   - **이 컴퓨터에서 시작**을 누릅니다.
2. **이 컴퓨터를 살펴보는 중…** (어디서 돌릴지 앱이 혼자 고릅니다. 고르는 화면은 나오지 않습니다)
   - 위에 파란 한 줄 **WSL Ubuntu-22.04 에서 사무실을 엽니다** 가 떠야 합니다. 이 PC는 Ubuntu-22.04에 사무실이 이미 있으니 그쪽을 고르는 게 맞습니다.
   - 다른 줄(예: **Windows 에서 바로 사무실을 엽니다**)이 뜨면 여기서 멈추고 화면을 찍어 보내 주세요.
   - WSL이 꺼져 있었으면 배포판이 켜지는 동안 몇 초 더 걸립니다.
3. **사무실을 찾는 중… → 로그인하는 중… → 연결됨**
   - 몇 초 안에 사무실 화면으로 넘어가야 합니다. 넘어간 뒤 사무실은 평소처럼 보여야 합니다(로그인 화면이 다시 나오면 실패).
   - **"이 컴퓨터에 Agent Tycoon을 설치할까요?"** 가 나오면 여기서 멈추세요. **설치는 누르지 마세요.** 지금 돌고 있는 사무실을 못 찾았다는 뜻입니다. 화면을 찍고 아래 5번처럼 로그를 보내 주세요.
4. **다시 열기**
   - 창의 X를 누르면 트레이로 숨습니다. 트레이 아이콘 → **종료**로 완전히 끕니다.
   - 다시 열면 첫 화면 없이 바로 사무실로 가야 합니다(고른 것이 저장됨).

**다른 방식으로 실행** (확인만, 3번까지 끝난 뒤): 진행 화면은 금방 지나가므로 **Ctrl+,** → 연결 방법 **이 컴퓨터** → **다음**으로 엽니다. 진행 화면이 멈춰 있을 때(예: 설치 질문)는 그 화면의 **자세히** → **다른 방식으로 실행**도 같은 화면을 엽니다.
예전 고르는 화면이 나옵니다: **WSL 배포판 Ubuntu-22.04에서 실행 (추천)**, **Windows에서 바로 실행**, **다른 컴퓨터에 연결**. 본 화면에 Node, npm, systemd 같은 말이 없어야 합니다.

**Windows에서 바로 실행**은 이 PC에서는 일부러 막혀 있습니다. WSL에 이미 사무실이 있으니 Windows에 하나 더 깔지 않습니다.
골라 보면 설치 없이 "WSL 배포판 Ubuntu-22.04에 이미 사무실이 있어 Windows에는 설치하지 않았습니다" 같은 안내나,
"다른 곳(다른 WSL 배포판이나 Windows)에서 도는 사무실이 이 포트를 쓰는 것 같습니다"가 나오고 아무것도 바뀌지 않아야 합니다. 그 뒤 **설정**에서 다시 Ubuntu-22.04를 고르면 됩니다.
Windows용 데몬은 R5 시험 묶음(포트 18250)으로 따로 봅니다. 그 묶음을 이미 깔았다면 이 항목이 그 사무실(18250)을 열 수도 있는데, 그것도 정상입니다.

## 3. 입력 점검 (실제 Windows에서만 볼 수 있는 것)

사무실 화면에서 하나씩 눌러 보고, 결과가 다르면 번호와 함께 알려 주세요. 자세한 표는 `cld/docs/design/g3-input-matrix.md`에 있습니다.

| 번호 | 할 일 | 이렇게 되면 정상 |
| --- | --- | --- |
| 1 | 바닥 빈 곳 우클릭, 캐릭터 우클릭 | 브라우저 메뉴는 안 뜸. 캐릭터 위에서는 캐릭터 메뉴 |
| 2 | 채팅 입력칸 우클릭 | 복사·붙여넣기 메뉴가 뜸 |
| 3 | 앱 첫 화면(설정 화면)의 빈 곳 우클릭, 설정의 입력칸 우클릭 | 빈 곳: 메뉴 안 뜸 / 입력칸: 복사·붙여넣기 메뉴 |
| 6 | 마우스 옆 버튼(뒤로·앞으로)을 사무실 바닥 위, 아래 카드 위, 앱 첫 화면에서. 게시판을 크게 띄운 채 뒤로 버튼 | 어디서도 다른 화면으로 안 감 / 크게 띄운 게시판만 닫힘 |
| 7 | 바닥에서 Ctrl+R / 터미널 안에서 Ctrl+R | 바닥: 새로고침되고 보던 위치 그대로 / 터미널: `reverse-i-search` |
| 8 | 바닥에서 F5 | Ctrl+R 과 똑같이 새로고침되고 보던 위치 그대로 |
| 9 | Ctrl+마우스 휠, 터치패드 두 손가락 벌리기 | 화면 전체가 커지지 않음. 그냥 휠은 사무실만 확대·축소 |
| 10 | Ctrl+= , Ctrl+- , Ctrl+0 | 화면 전체 크기 그대로 |
| 11 | 터치패드 두 손가락으로 좌우 쓸기 | 뒤로·앞으로 안 감 |
| 12 | 바닥에서 휠 버튼 누른 채 끌기 | 사무실이 끌려 움직임. 자동 스크롤 동그라미가 안 뜸 |
| 14 | 채팅에 한글 입력, 마지막 글자 조합 중에 Enter | 글자가 깨지지 않고, 조합 중 Enter로 반쪽 글자가 보내지지 않음 |
| 15 | Alt+← , Alt+→ (키보드에 뒤로 키가 있으면 그것도) | 다른 화면으로 안 감. 게시판을 크게 띄운 채 Alt+← 면 그것만 닫힘 |
| 17 | Ctrl+Shift+I, F12 | 개발자 도구가 안 뜸 |
| 18 | F11, Ctrl+Shift+T, Ctrl+, | 전체 화면 / 항상 위(트레이 메뉴에 표시) / 설정 화면 |

## 4. 같이 볼 것

- 사무실 안의 바깥 링크(문서, 변경 내역 등)는 앱 안이 아니라 기본 브라우저에서 열려야 합니다.
- 트레이 메뉴: 열기 · 설정 · 다시 연결 · 항상 위 · 종료가 다 있어야 합니다.

## 5. 안 될 때 보내 줄 것

1. 멈춘 화면을 그대로 찍은 사진(**자세히**가 있으면 펼친 채로).
2. 앱 로그: 탐색기 주소창에 `%LOCALAPPDATA%\dev.cldgui.pixeloffice\logs` 를 넣으면 `agent-tycoon.log`가 있습니다. 파일째 보내 주세요.
   로그에는 연결 단계만 남고 비밀번호, 로그인 코드, 토큰은 남지 않습니다.
3. 사무실(데몬) 쪽 로그가 필요하면 WSL에서 `~/.config/cld-gui/daemon.log`의 끝부분.
4. 몇 번 화면에서, 무엇을 눌렀을 때인지 한 줄.

## 6. 지우기

1. 트레이 아이콘 → **종료**로 앱을 끕니다.
2. Windows 설정 → 앱 → 설치된 앱 → **Agent Tycoon** → 제거.
3. **Delete the application data**(앱 데이터 삭제)를 **체크하지 않으면**, 이 앱이 Windows에 설치한 데몬 프로그램·로그온 예약 작업은 함께 지우고 `%USERPROFILE%\.config\cld-gui` 설정은 남깁니다.
4. **체크하면**, 위 항목과 Windows용 `%USERPROFILE%\.config\cld-gui` 설정까지 지웁니다. 이 선택은 Pixel Office와 같이 쓰는 `%APPDATA%\dev.cldgui.pixeloffice`도 지우므로, Pixel Office의 저장된 연결과 이 기기 SSH 키까지 정리할 때만 고르세요.
5. WSL의 사무실(데몬)과 그 데이터는 두 경우 모두 그대로 남습니다. 이 시험에서는 Windows용 `agty.cmd`가 없으므로 앱 제거가 WSL에 명령을 보내지 않습니다.
