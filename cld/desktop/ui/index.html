    예전에 설치한 사무실이 있지만 지금 응답하지 않습니다. 다시 켜지는 중이면 잠시 뒤 다시 연결을 누르세요. 설치를 누르면 예전 사무실의 자동 시작을 끄고 Agent Tycoon이 이어받습니다. 데이터는 그대로 두고, 나중에 되돌릴 수 있어요.

    Agent Tycoon을 언제 실행할까요?
    자세히

    이 앱에 들어 있는 사무실 프로그램(서명 확인)을 설치 관리자(agty install)에게 넘깁니다. 인터넷이 없어도 됩니다. WSL을 고르면 그 배포판 안 ~/.local/share/agent-tycoon 에, Windows는 %LOCALAPPDATA%\AgentTycoon 에, Linux는 ~/.local/share/agent-tycoon, macOS는 ~/Library/Application Support/AgentTycoon 에 설치하고 자동 시작(사용자 서비스 agent-tycoon)을 등록합니다. 예전 소스 설치(cld-gui 서비스)는 데이터를 그대로 둔 채 이어받고, agty revert-adopt 로 되돌릴 수 있습니다. 지울 때는 agty uninstall --program 입니다.

    직접 시작하도록 정해 두었어요.
