에이전트 타이쿤 0.1.0-rc.2

- 업데이트: 새 버전이 GitHub 에 나오면 1시간 안에 알려 드려요. Windows 에서도 '설치' 단추로 올라가요. 설정 › 일반에서 지금 버전과 마지막 확인을 보고 '지금 확인'을 누를 수 있어요.
- 화면: 모던 테마(기본)와 픽셀 테마. 폰에서 글자·줄 간격을 다듬었고, 픽셀 테마의 한글이 네모로 나오던 것을 고쳤어요.
- 메신저: 폰 대화 머리 정리, 문단 사이 빈 줄이 보여요. 단어는 머지·클론·워커·워크트리처럼 개발자가 쓰는 말로 바꿨어요.
- 사용량: 에이전트 CLI 마다 지금 버전 → 새 버전과 업데이트 단추. 새로고침은 맨 윗줄에 있어요.
- 사무실: 쉬는 에이전트가 소파 하나에 겹쳐 쌓이지 않아요. 로딩 화면은 끝난 순서대로 켜져요.
- 옆 건물(시험): 다른 PC 를 짝 코드로 붙여 그 사무실의 요약을 볼 수 있어요.
- 보안: 연결이 끊긴 동안 누른 허락이 다시 켜진 뒤 다른 요청을 허락하던 문제를 고쳤어요.
