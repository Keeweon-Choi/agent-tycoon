에이전트 타이쿤 0.1.0-rc.10

0.1.0-rc.9 는 게시되지 않았어요. 이 노트는 rc.8 뒤의 변경을 모두 담아요.

메신저
- 새 기능: 사이드 질문. 일하는 리드의 대화를 끊지 않고 옆 서랍에서 물어봐요. 리드 대화의 읽기 전용 사본이 고른 모델로 답하고, 사무실에 에이전트로 나타나지 않아요. 서랍을 닫으면 멈추고, "리드에게 전달"로 일반 메시지 하나를 보낼 수 있어요. 실패하면 다시 로그인할지, 사용량 한도인지, CLI 가 한 말인지 이유를 보여 줘요.
- 새 기능: / 목록이 쓰는 사람의 Claude Code CLI 에서 명령을 읽어 와요. 방향키로 고르고, 인자는 힌트로 보여 주고, 그냥 /model 은 CLI 의 선택창을 시트로 열어요. 일하는 중인 리드에게 보낸 /model 도 열려요. 선택창이나 대화창이 열려 있으면 메시지를 그 안에 치지 않고 붙들어 뒀다가 닫힌 뒤 넣어요.
- 고친 것: 메신저에서 보낸 / 명령이 선택창을 닫은 뒤에도 "보냄"으로 맨 아래에 남던 문제. 터미널에서 친 명령도 대화에 보여요.
- 고친 것: 다른 대화 탭, 분할 화면, 단톡방 탭으로 갔다 돌아오면 맨 아래로 튀던 문제. 읽던 자리를 기억해요.
- 고친 것: 에이전트의 긴 답이 4000자에서 잘리던 문제. 더 보기로 전체가 열려요(24,000자).
- 고친 것: 줄이 .png 로 끝나는 긴 메시지가 에이전트 입력창에 제출되지 않고 남아, 뒤 메시지가 몇 시간씩 막히던 문제. 붙여넣은 글이 보인 뒤에 Enter 를 누르고, 10분 넘게 입력창에서 기다리는 메시지는 한 번 알려 줘요.
- 단톡방: 글타래는 접힌 채로 시작하고, 답글 수가 바로 보여요. 알림에는 받은 멤버가 표시돼요.
- 고친 것: 연결이 끊긴 사이 보낸 수정과 쓰던 초안이 사라지던 문제.
- 고친 것: 대화 목록에서 쉬거나 꺼진 에이전트가 시각 없이 "대화 없음"으로 뜨던 문제. 켜져 있든 꺼져 있든 마지막 메시지 시각 순으로 정렬돼요.

엔진·안정성
- 새 기능: 설정 폼의 모델을 목록에서 골라요(CLI 가 쓰는 이름 그대로).
- 고친 것: 대화에서 /model 로 바꾼 모델이 교대나 재시작 뒤 옛 값으로 돌아가던 문제.
- 고친 것: 재부팅 뒤 쉬던 대화가 전부 다시 깨어나던 문제. 60분 넘게 쉰 대화를 멈추는 기능도 다시 동작해요.
- 고친 것: 예전 버전이 저장한 새 Worker 승인이 원격 연결에서 다시 인증하는 단계를 건너뛰던 문제.
- 고친 것: 워크트리 정리가 안에 별도 git 저장소(git init, git clone)가 든 워크트리를 지우던 문제. 이제 거절해요. 안에 다른 워크트리나 서브모듈이 있거나 분리된 HEAD 인 경우에도 작업을 지우지 않아요.
- 새 기능: 에이전트가 시킨 작업(job)이 끝나면 알리는 --notify 와 agty wait. agty job --help 는 작업을 시작하지 않고 사용법만 보여 줘요.
- 고친 것: 이어서 연 대화(/resume)가 옛 질문을 다시 띄우던 문제, 승인한 도구의 권한 말풍선이 남던 문제, 이름표 고리가 질문 대기를 쉼으로 보이던 문제.
- 고친 것: Windows 에서 codex.exe 를 못 찾던 문제, ACP 에이전트를 멈출 때 하위 프로세스가 남던 문제.

보안
- 장치를 폐기하면 그 장치로 이어진 패스키 로그인까지 닫아요. 원격 세션에서 에이전트 터미널에 붙으려면 다시 인증해야 해요. 파일 저장은 임시 파일을 거쳐 바꿔요.

현황판·개발실·사무실·폰
- 새 기능: 현황판의 타임라인 탭. 사장님 메시지, 리드, 서브에이전트, Codex, 작업(job)이 언제 시작해 언제 끝났는지 시간 축에 그려요. 실패한 실행은 실패로 표시하고, 데몬이 보지 못한 시작이나 끝은 모른다고 적어요.
- 새 기능: 현황판의 차례대로 확인하기. 검토에 쌓인 이슈를 한 건씩 보여 줘요: 무엇이 문제였고 무엇을 바꿨는지, 확인 순서, 전·후 사진. "확인했어요"는 이슈를 끝내고, "아직 이상해요"는 적은 한 줄과 함께 리드에게 돌려보내요. 확인하면 브랜치가 머지되는 경우에만 그렇게 알려 줘요.
- 새 기능: 개발실의 이슈 보기와 브랜치 보기. 워크트리 트리와 전환해서 봐요. 이슈 보기는 일 하나가 맡겨져 머지되기까지의 흐름을, 브랜치 보기는 기준 브랜치 줄기와 고치는 가지, 오늘 머지된 것을 그려요.
- 고친 것: 사무실에서 일하는 직원을 클릭해 따라가는 동안 방향키(WASD)가 듣지 않던 문제.
- 고친 것: 폰 터미널의 Face ID 단추가 iPhone 에서 패스키 창을 바로 열어요.
- 고친 것: 폰에서 캐릭터를 탭하면 선택만 되고, 걷기 패드로 걷게 할 수 있어요. 상단 바가 화면 스타일을 따라요.
- 고친 것: 배치 편집기의 실행 취소와 칸 넓히기, 한 자리에 캐릭터 둘이 앉던 문제, 아이소 가구 방향.
- 고친 것: 연결이 끊긴 사이 개발실의 diff 가 계속 로딩 중으로 남던 문제, 편집 중인 파일을 다른 루트로 바꿀 때 묻지 않던 문제.

설치·데스크톱
- 고친 것: Windows 업데이트가 로그온 시작 설정을 지우던 문제, 제거가 남의 파일까지 지우던 문제, 설치 스크립트가 실패한 줄을 알려 주지 않던 문제.
