the 모던 style (`:root[data-ui-theme='modern']`), the 픽셀 감성 style never asks for them.
SemiBold (600) answers for every strong weight (600 to 700): the GPT mockups' names and heads are
SemiBold, and Bold read as heavy blots at the phone's sizes (owner 11-06 21:08).
